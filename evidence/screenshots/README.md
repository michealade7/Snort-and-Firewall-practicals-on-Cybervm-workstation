# Screenshots

Save genuine screenshots from your own lab here. Suggested evidence:

1. VirtualBox CyberOps Workstation network settings.
2. CyberOps Workstation DHCP/interface result.
3. Successful connectivity test (if available).
4. Mininet started and `mininet>` prompt.
5. R1 Snort initialization.
6. H10 server listening on TCP port 6666.
7. Snort alert after the H5 request.
8. H5 download result.
9. tcpdump capture summary and PCAP file listing.
10. `iptables -L -v` before and after the DROP rule.
11. H5 request failing after the firewall rule.
12. Mininet cleanup result.

Use descriptive filenames, for example `01-virtualbox-network.png`. Do not use sample screenshots from the handout as evidence of your own execution.
